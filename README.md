# バレー動画タグ付け（Volley-video-timelogger）

YouTube のバレーボールの試合動画を見ながら、サーブやスパイクなどの場面をボタン一つで記録するツールです。記録は表で確認でき、行をタップするとその場面に戻れます。CSV で書き出し・読み込みもできます。

`index.html` の 1 ファイルだけで動きます。サーバーやインストールは要りません。スマホでの操作を想定しています。

## 使い方

1. YouTube の動画か再生リストの URL を入れて「読込」を押す
2. 必要ならチーム名（初期値は「Aチーム」「Bチーム」）を書き換える
3. 動画を見ながら、場面ごとにボタンを押す
4. 終わったら「CSV書き出し」で保存する

### 動画のタップ操作

iPad などではプレーヤーにダブルタップの 10 秒スキップがないので、このツール側で用意しています。

- 動画の左側をダブルタップ: 10 秒戻す
- 動画の右側をダブルタップ: 10 秒進める（続けてタップすると 10 秒ずつ増える）
- 1 回タップ: 再生 / 一時停止
- 長押し: 押している間だけ 2 倍速（離すと元の速さに戻る）
- 下の操作バー（シークバー・全画面ボタンなど）はそのまま使えます
- 動画を読み込んだ直後は、最初の 1 回だけプレーヤーの再生ボタンを押してください。再生が始まるとタップ操作が使えるようになります
- 全画面表示中は YouTube 側の操作になるため、ダブルタップのスキップと長押しの 2 倍速は使えません

### チーム名（動画ごと）

チーム名は動画ごとに覚えます。1 本の再生リストに別の試合が入っていても、動画ごとに名前を付けられます。

- 名前を書き換えるか、その動画で最初に記録したときに、その動画のチーム名として保存されます
- まだ名前のない動画を開くと、再生リストで手前にある一番近い動画の名前が入ります（なければ直前に入っていた名前のまま）。同じ試合の続きならそのまま記録できます
- 名前を付けた動画に戻ると、その動画の名前に切り替わります
- 再生リストの記録の表では、動画の見出しに「東高 vs 西高」のように対戦が出ます

### 記録する時刻

プレーを見てからボタンを押すまでには少し遅れがあるので、記録する時刻は「ボタンを押した時刻の 3 秒前」にしています。ボタンの下の「記録する時刻：ボタンを押した ◯ 秒前」で秒数を 0〜10 秒（1 秒刻み）から選べます（0 にすると押した時刻そのまま）。設定はブラウザが覚えます。

- 表・コメント欄用コピー・CSV の時刻は、すべてこの記録した時刻です
- 秒数を変えても、すでに記録したものの時刻は変わりません

### ボタン

| ボタン | 記録される内容 |
| --- | --- |
| サーブ（A / B） | どちらのチームのサーブか。押すたびにラリー番号が 1 つ進む |
| 注目スパイク | 注目したいスパイク |
| 見返したい | 動画が一時停止してメモの入力欄が出る。「記録する」を押すと、ボタンを押した時点の時刻とメモを記録する（「キャンセル」なら記録しない）。閉じると再生に戻る |
| セット切替 | ここから次のセット |
| 取り消す | 最後に記録したものを取り消す。確認画面が出て、出ている間は動画が一時停止する（閉じると再生に戻る） |
| コメント欄用にコピー | 今の動画の記録を、YouTube のコメント欄に貼れる形でコピーする（下記） |

### 再生リストの動画を選ぶ

再生リストの URL を読み込むと、動画の下にリスト内の動画のタイトルが選択欄で並びます。選ぶとその動画に切り替わります。記録がある動画には `［5件］` のように件数が付きます。

タイトルは YouTube の oEmbed（つながらないときは noembed.com）から 1 本ずつ取得します。非公開や削除済みの動画は「タイトルを取得できません」と出ます。

### 記録の表

- 初めは新しい順（動画の時刻が後のものが上）に並びます。「新しい順 ▼ / 古い順 ▲」のボタンで切り替えられ、選んだ順はブラウザが覚えます
- 最後に記録した行には、左端に黄色い印が付きます
- 表の上のボタン（すべて / サーブ / 注目スパイク / 見返したい）で、種類ごとに絞り込めます。ボタンの数字はその種類の件数です。絞り込み中もセットの区切りは表示されます。絞り込みは表示だけで、コメント欄用コピーと CSV には全部の記録が入ります
- 行をタップすると、記録した時刻から再生します（再生リストの別の動画にも移動します）
- メモ欄に自由に書き込めます
- `×` でその行を消します。「全消去」で全部消します
- 再生リストの場合は、動画ごとに見出しが付きます

### セット・ラリー・点数の数え方

- 「セット-R」列は「セット番号-ラリー番号」です。サーブを記録するたびにラリー番号が 1 つ進みます。サーブ以外の記録には直前のサーブと同じ番号が付きます
- 「点数」列は、そのラリーが始まる時点の「A チーム-B チーム」の点数です
  - ラリーに勝ったチームが次にサーブするので、セットの 2 本目以降のサーブは、サーブしたチームの 1 点として数えます（1 本目のサーブは 0-0）
  - サーブ以外の記録は、直前のサーブと同じ点数です
  - セットの最後のラリーはどちらが取ったか記録に残らないので、セットの最終スコアは出ません
  - サーブを記録し忘れると、そこから点数がずれます
- 動画ごとに第 1 セットから数え直します
- 「セット切替」は、そのセットでサーブが 1 本以上記録されているときだけ次のセットに進みます。試合が始まる前に押しても第 1 セットのままです

## YouTube のコメント欄用にコピー

「コメント欄用にコピー」を押すと、コピーする記録を選ぶ画面が出ます。

- 種類（サーブ / 注目スパイク / 見返したい など）にチェックを入れると、その種類の記録をまとめて選べます。複数選べます
- 「一つずつ選ぶ」を押すと記録の一覧が開き、記録ごとにチェックを付け外しできます
- 「コピー（◯件）」を押すと、選んだ記録を次の形でクリップボードにコピーします
- 外した種類はブラウザが覚えていて、次に開いたときも外れたままです

YouTube のコメント欄に貼ると、時刻がその場面へのリンクになります。

```
東高 vs 西高

0:00 ━━ 第1セット開始 ━━
0:07 サーブ（東高） - ナイスコース
0:12 注目スパイク
0:37 サーブ（西高）

1:07 ━━ 第2セット開始 ━━
1:17 サーブ（西高）
```

- 時刻は記録した時刻そのままです
- セットの見出しは、選んだ記録があるセットにだけ付きます
- メモがあれば ` - ` のあとに付きます
- 再生リストの場合は、いま再生している動画の分だけをコピーします（記録が 1 本分しかなければ、その動画の分）
- YouTube のコメントは 1 万文字までです。超えるときは画面にお知らせが出ます

## CSV

「CSV書き出し」でファイルを保存します。保存できない端末では画面に CSV の文字が出るので、「コピー」でメモアプリなどに貼り付けてください。

「CSV読み込み」で、書き出した CSV の記録を今の記録に追加できます（置き換えはしません）。

- ファイルを選ぶと、取り込む種類（サーブ / 注目スパイク / 見返したい / セット切替 など）を選ぶ画面が出ます。種類ごとに追加される件数と重複の件数が出ます
- 同じ動画・同じ種類・同じサーブ側で、時刻の差が 1 秒未満の記録は重複として取り込みません。重複した記録でも、今の記録のメモが空で CSV 側にメモがあれば、メモだけ写します
- チーム名は、まだ名前の付いていない動画にだけ CSV の名前を入れます。すでに付けた名前は変わりません

列は次のとおりです。

| 列名 | 内容 |
| --- | --- |
| `video_id` | YouTube の動画 ID |
| `video_title` | 動画タイトル |
| `playlist_id` | 再生リスト ID（ないときは空） |
| `playlist_index` | 再生リストの何本目か |
| `team_a` / `team_b` | その動画のチーム名 |
| `set` | セット番号 |
| `seconds` | 動画の秒数 |
| `time` | 時刻（`分:秒` または `時:分:秒`） |
| `rally` | ラリー番号 |
| `score_a` / `score_b` | そのラリーが始まる時点の点数 |
| `type` | 種類（サーブ、注目スパイクなど） |
| `serve_side` | `A` / `B` |
| `serve_team` | チーム名 |
| `memo` | メモ |

## 共有リンク

「リンクをコピー」で、今の動画（または再生リスト）と、今表示しているチーム名を入れたリンクをコピーします。このリンクを開くと、同じ動画がすぐ読み込まれます。記録の中身はリンクに入りません。共有するときは CSV を渡してください。

リンクには次の指定が使えます。

| 指定 | 意味 |
| --- | --- |
| `yt=<YouTubeのURL>` | 動画や再生リストの URL をそのまま渡す |
| `v=<動画ID>` | 動画 ID |
| `list=<再生リストID>` | 再生リスト ID |
| `t=90` | 開始位置（秒。`1m30s` の形も可） |
| `index=3` | 再生リストの何本目から始めるか |
| `ta=<名前>` / `tb=<名前>` | チーム名 |

例: `index.html?v=XXXXXXXXXXX&ta=東高&tb=西高&t=120`

## 公開のしかた

YouTube の埋め込み再生は、ファイルを直接開く（`file://`）と動かないことがあります（エラー 153）。Web アドレスで開いてください。

GitHub Pages を使う場合:

1. リポジトリの **Settings → Pages** を開く
2. **Source** を「Deploy from a branch」、ブランチを `main`、フォルダを `/ (root)` にして保存する
3. しばらくすると `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けるようになる

## 注意

- 記録・チーム名・見ていた動画と位置は、ブラウザに自動で保存されます。再読み込みしたり閉じて開き直したりしても、そのまま続きから使えます
- 保存先はそのブラウザの中だけです。別の端末や別のブラウザには引き継がれません。ブラウザのデータを消すと記録も消えるので、大事な記録は CSV で書き出しておいてください
- プライベートブラウズなどで保存できないときは、記録があると閉じる前に確認が出ます
- 埋め込み再生が禁止されている動画や、非公開の動画は再生できません
