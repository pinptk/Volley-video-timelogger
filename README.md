# バレー動画タグ付け（Volley-video-timelogger）

YouTube のバレーボールの試合動画を見ながら、サーブやスパイクなどの場面をボタン一つで記録するツールです。記録は表で確認でき、行をタップするとその場面に戻れます。CSV で書き出し・読み込みもでき、Firebase（Firestore）のデータベースを使えば、ほかの人と記録を同期することもできます。

`index.html` の 1 ファイルだけで動きます。サーバーやインストールは要りません。スマホでの操作を想定しています。

LINE などでリンクを送ったときのプレビューの文字は、`index.html` の `<head>` にある `description` と `og:` で始まる `meta` タグで決まります。変えたら、LINE 側に古いプレビューが残っていることがあるので、しばらくしてから確認してください。

## 使い方

1. YouTube の動画か再生リストの URL を入れて「読込」を押す
2. 必要ならチーム名（初期値は「Aチーム」「Bチーム」）を書き換える
3. 動画を見ながら、場面ごとにボタンを押す
4. 終わったら「記録ファイル読み書き」の「書き出し」で保存するか、「データベースと同期」でデータベースに送る

### 設定

右上の「設定」を押すと、設定の画面が出ます。見出しを押すと開きます。

- **動画プレーヤーの設定**: 次の 3 つのオン・オフ（ブラウザが覚えます）
  - 再生リストの自動再生（初めはオフ）: オンにすると、動画が終わったら再生リストの次の動画に進みます（「再生リストで次の動画に進まない」を参照）
  - ダブルタップで 10 秒スキップ（初めはオン）: オフにすると、動画の左右をダブルタップしてもスキップしません。そのかわり、1 回タップの再生・一時停止が待たずにすぐ効きます
  - 長押しで 2 倍速（初めはオン）: オフにすると、長押ししても速さは変わりません
- **データベース**: データベースの接続先と合言葉の設定（「データベースと同期」を参照）。設定リンクのコピー、つながるかの確認（「接続確認」）、変更、この端末の設定を消す（記録は消えません）ができます
- **データベースの用意のしかた**: Firebase の準備の手順。Firestore に貼るルールが出ていて、「ルールをコピー」でコピーできます（中身はこのリポジトリの `firestore.rules`）
- **使い方**: このツールの使い方の要約

### クリア

「リンクをコピー」の横の「クリア」を押すと、動画を止めて、URL 欄とチーム名を空で開いたときの状態（「Aチーム」「Bチーム」）に戻します。

- 記録と「動画一覧」の見た動画は消えません。その動画をまた開けば、記録もチーム名も戻ります
- このタブで開いていた動画も忘れるので、クリアしたあとに読み込み直しても空の状態のままです

### 動画一覧

「読込」の右の「動画一覧」を押すと、動画の一覧が出ます。

- データベースを設定している人（「データベースと同期」を参照）には、「見た動画」と「データベースにある動画」のボタンが出ます。押した方の一覧が出て、もう一方のボタンで切り替えられます
- データベースを設定していない人には、見た動画の一覧がそのまま出ます

#### 見た動画

今まで開いた動画が新しい順に最大 100 本まで出ます。タップするとその動画を、前に見ていた位置から開きます（再生リストの中の動画なら再生リストごと）。各動画には、開いた日時・チーム名・記録の件数が出ます。再生リストの中の動画には、再生リストの名前も出ます（YouTube の oEmbed から取得。取れなかったときは「名前を取得できていません」）。

各動画の右の「×」で一覧から消せます。記録がある動画は「一覧からだけ消す」か「記録も一緒に消す」かを選べます。

古いものは消えていることがあります（しばらく使わないと、ブラウザが保存データを消すことがあるため）。

#### データベースにある動画

今の合言葉でデータベースにある動画が、新しく同期された順に出ます。開くたびにデータベースから読み直します。各動画には、最後に同期された日時・チーム名・データベースの記録の件数・この端末の記録の件数が出ます。再生リストの中の動画には、再生リストの名前も出ます。

タップするとその動画を開きます（再生リストの中の動画なら再生リストごと）。開いただけでは記録は取り込まれないので、「データベースと同期」で同期してください。この一覧からは消せません。

### 動画のタップ操作

iPad などではプレーヤーにダブルタップの 10 秒スキップがないので、このツール側で用意しています。

- 動画の左側をダブルタップ: 10 秒戻す
- 動画の右側をダブルタップ: 10 秒進める（続けてタップすると 10 秒ずつ増える）
- 1 回タップ: 再生 / 一時停止
- 長押し: 押している間だけ 2 倍速（離すと元の速さに戻る）
- 動画の上の帯（設定・音量など）と下の帯（シークバー・共有・全画面ボタンなど）はタップ操作の範囲から外しているので、そのまま使えます
- 動画を読み込んだ直後は、最初の 1 回だけプレーヤーの再生ボタンを押してください。再生が始まるとタップ操作が使えるようになります
- 全画面表示中は YouTube 側の操作になるため、ダブルタップのスキップと長押しの 2 倍速は使えません
- ダブルタップのスキップと長押しの 2 倍速は、「設定」の「動画プレーヤーの設定」でそれぞれオフにできます

### チーム名（動画ごと）

チーム名は動画ごとに覚えます。1 本の再生リストに別の試合が入っていても、動画ごとに名前を付けられます。

- 名前を書き換えるか、その動画で最初に記録したときに、その動画のチーム名として保存されます
- まだ名前のない動画を開くと、再生リストで手前にある一番近い動画の名前が入ります（なければ直前に入っていた名前のまま）。同じ試合の続きならそのまま記録できます
- 名前を付けた動画に戻ると、その動画の名前に切り替わります

### 記録する時刻

プレーを見てからボタンを押すまでには少し遅れがあるので、記録する時刻は「ボタンを押した時刻の 3 秒前」にしています。ボタンの下の「記録する時刻：ボタンを押した ◯ 秒前」で秒数を 0〜10 秒（1 秒刻み）から選べます（0 にすると押した時刻そのまま）。設定はブラウザが覚えます。

- 表・コメント欄用コピー・CSV の時刻は、すべてこの記録した時刻です
- 秒数を変えても、すでに記録したものの時刻は変わりません

### ボタン

| ボタン | 記録される内容 |
| --- | --- |
| サーブ（A / B） | どちらのチームのサーブか。押すたびにラリー番号が 1 つ進む。**ダブルタップ**すると「前のラリーはノーカウント」のサーブとして記録し、前のラリーの点をどちらにも足さない（ボタンの「?」を押すと説明が出る） |
| 注目スパイク | 注目したいスパイク |
| 見返したい | 動画が一時停止してメモの入力欄が出る。「記録する」を押すと、ボタンを押した時点の時刻とメモを記録する（「キャンセル」なら記録しない）。閉じると再生に戻る |
| セット切替 | ここから次のセット |
| 取り消す | いま再生している動画で最後に記録したものを取り消す。確認画面が出て、出ている間は動画が一時停止する（閉じると再生に戻る） |
| コメント欄用にコピー | 今の動画の記録を、YouTube のコメント欄に貼れる形でコピーする（下記） |
| 記録ファイル読み書き | 「書き出し」と「読み込み」のボタンが出る。記録を CSV ファイルに書き出すか、CSV ファイルから読み込む（下記） |
| データベースと同期 | データベースと記録をやりとりする（下記） |

### 再生リストの動画を選ぶ

再生リストの URL を読み込むと、動画の下にリスト内の動画のタイトルが選択欄で並びます。選ぶとその動画に切り替わります。記録がある動画には `［5件］` のように件数が付きます。

タイトルは YouTube の oEmbed（つながらないときは noembed.com）から 1 本ずつ取得します。非公開や削除済みの動画は「タイトルを取得できません」と出ます。


### 再生リストで次の動画に進まない

再生リストの動画が終わっても、次の動画には自動で進みません（YouTube の埋め込みプレーヤーには止める設定がないので、このツールが終わる直前で一時停止します）。

- 画面が裏にあったなどで止めるのが間に合わずに次の動画に進んだときは、前の動画の終わりに戻して「次の動画には進まないようにしています」と出します
- 「前の動画／次の動画」ボタン、選択欄、記録の行のタップなどで自分で移るのは、今までどおりできます
- 進ませたいときは、「設定」の「動画プレーヤーの設定」で「再生リストの自動再生」をオンにしてください（ブラウザが覚えます）
- 終わる直前で止めるので、動画の最後の 1 秒ほどは再生されません
### 記録の表

- 初めは新しい順（動画の時刻が後のものが上）に並びます。「新しい順 ▼ / 古い順 ▲」のボタンで切り替えられ、選んだ順はブラウザが覚えます
- 最後に記録した行には、左端に黄色い印が付きます
- いまの再生位置のすぐ前の記録には、左端に青い印が付きます（再生に合わせて動きます）
- 表の上のボタン（すべて / サーブ / 注目スパイク / 見返したい）で、種類ごとに絞り込めます。ボタンの数字はその種類の件数です。絞り込み中もセットの区切りは表示されます。絞り込みは表示だけで、コメント欄用コピーと CSV には全部の記録が入ります
- 行をタップすると、記録した時刻から再生します（再生リストの別の動画にも移動します）
- メモ欄に自由に書き込めます。入りきらないメモは折り返して表示します（Enter で入力を終えます。メモの中では改行しません）
- 表に出るのは、いま再生している動画の記録だけです。ほかの動画の記録も保存されていて、その動画に切り替えると表に出ます（再生リストの選択欄に動画ごとの件数が出ます）
- `×` でその行を消します。「この動画の記録を消去」で、いま再生している動画の記録を全部消します（ほかの動画の記録は消えません）。どちらも確認の画面が出て、出ている間は動画が一時停止します

### セット・ラリー・点数の数え方

- セットは、表の「第◯セット 開始」の行で区切られます
- サーブを記録するたびにラリー番号が 1 つ進みます。サーブ以外の記録には直前のサーブと同じ番号が付きます。ラリー番号は表には出さず、記録ファイル（CSV）の `rally` 列に入ります
- 「点数」列は、そのラリーが始まる時点の「A チーム-B チーム」の点数です
  - ラリーに勝ったチームが次にサーブするので、セットの 2 本目以降のサーブは、サーブしたチームの 1 点として数えます（1 本目のサーブは 0-0）
  - サーブ以外の記録は、直前のサーブと同じ点数です
  - サーブボタンをダブルタップしたサーブ（表に「ノーカウント」と出る）は、前のラリーをノーカウントとして、どちらにも点を足しません
  - セットの最後のラリーはどちらが取ったか記録に残らないので、セットの最終スコアは出ません
  - サーブを記録し忘れると、そこから点数がずれます
- 動画ごとに第 1 セットから数え直します
- 「セット切替」は、そのセットでサーブが 1 本以上記録されているときだけ次のセットに進みます。試合が始まる前に押しても第 1 セットのままです

## YouTube のコメント欄用にコピー

「コメント欄用にコピー」を押すと、コピーする記録を選ぶ画面が出ます。

- 種類（サーブ / 注目スパイク / 見返したい など）にチェックを入れると、その種類の記録をまとめて選べます。複数選べます
- 「一つずつ選ぶ」を押すと記録の一覧が開き、記録ごとにチェックを付け外しできます
- 「コピー（◯件）」を押すと、選んだ記録を次の形でクリップボードにコピーします
- 外した種類はブラウザが覚えていて、次に開いたときも外れたままです

YouTube のコメント欄に貼ると、時刻がその場面へのリンクになります。

```
東高 vs 西高

0:00 ━━ 第1セット開始 ━━
0:07 サーブ（東高） - ナイスコース
0:12 注目スパイク
0:37 サーブ（西高）

1:07 ━━ 第2セット開始 ━━
1:17 サーブ（西高）
```

- 時刻は記録した時刻そのままです
- セットの見出しは、選んだ記録があるセットにだけ付きます
- メモがあれば ` - ` のあとに付きます
- 再生リストの場合は、いま再生している動画の分だけをコピーします（記録が 1 本分しかなければ、その動画の分）
- YouTube のコメントは 1 万文字までです。超えるときは画面にお知らせが出ます

## 記録ファイル（CSV）

記録は CSV 形式のファイルで書き出し・読み込みできます。「記録ファイル読み書き」を押すと「書き出し」と「読み込み」のボタンが出るので、どちらかを選びます。

「書き出し」を押すと、書き出す動画を選ぶ画面が出ます。

- 記録のある動画が「再生中の動画」「この再生リストのほかの動画」「ほかの動画」に分かれて並びます。初めは再生中の動画だけにチェックが入っています
- チェックで動画を選べます。「再生中の動画だけ」「すべて選ぶ」でまとめて切り替えられます
- 「書き出す（◯本・◯件）」でファイルを保存します。ファイル名は `<動画タイトル>_<書き出した日時>.csv`（例: `練習試合_20261109_1530.csv`）です。複数の動画を書き出すときは `<最初の動画タイトル>_他2本_<日時>.csv` になります。ファイル名に使えない記号は `_` に置き換えます
- 保存できない端末では画面に CSV の文字が出るので、「コピー」でメモアプリなどに貼り付けてください

「読み込み」を押してファイルを選ぶと、書き出したファイルの記録を今の記録に追加できます（置き換えはしません）。

- ファイルを選ぶと、取り込む種類（サーブ / 注目スパイク / 見返したい / セット切替 など）を選ぶ画面が出ます。種類ごとに追加される件数と重複の件数が出ます
- 複数人が同じ動画を別々に記録して、CSV で渡し合うことを想定して、重複は次のように判断します
  - 同じ記録（記録ごとの固有番号 `record_id` が同じ）は取り込みません。人づてに回ってきた CSV でも重なりません
  - サーブは、同じ動画・同じチームのサーブが 6 秒以内にあれば、同じサーブとして取り込みません（人によって押すタイミングがずれるため）
  - セット切替は、同じ動画で 5 分以内にあれば取り込みません
  - 注目スパイク・見返したいは、1 秒未満の差でメモが同じか片方が空なら取り込みません。メモが違えば別の記録として追加します
  - 重複した記録でも、CSV 側にしかないメモは「今のメモ / CSV のメモ」とつなげて残します
  - 同じサーブに、ファイル側だけ「ノーカウント」の印があれば、印を写します
- チーム名は、まだ名前の付いていない動画には CSV の名前を入れます
- 自分で付けたチーム名と CSV のチーム名が違う動画があると、読み込み画面に「チーム名の対応」が出ます。自分のどちらのチームが CSV のどちらにあたるかを選んでください（名前の似ている方が最初から選ばれています）
  - その動画の記録は、CSV のチーム名と A・B に合わせます。A・B が反対なら、今までの記録の A・B を入れ替えます。CSV に書き出すときも CSV 側の名前で書き出すので、渡し合っても食い違いません
  - 画面（入力欄・サーブボタン・表・点数・コメント欄用コピー）は、自分のチーム名と左右の並びのままです。左のサーブボタンが中では B として記録されることもありますが、表示は変わりません
  - その後に入力欄でチーム名を書き換えても、変わるのは自分の表示名だけです
- 読み込んだファイルの動画が、今見ている動画と違うときは「別の動画の記録です」と出て、その動画を開くかどうかを選べます（ファイルに動画が複数あれば、開く動画を選べます）

列は次のとおりです。

| 列名 | 内容 |
| --- | --- |
| `video_id` | YouTube の動画 ID |
| `video_title` | 動画タイトル |
| `playlist_id` | 再生リスト ID（ないときは空） |
| `playlist_index` | 再生リストの何本目か |
| `team_a` / `team_b` | その動画のチーム名 |
| `set` | セット番号 |
| `seconds` | 動画の秒数 |
| `time` | 時刻（`分:秒` または `時:分:秒`） |
| `rally` | ラリー番号 |
| `score_a` / `score_b` | そのラリーが始まる時点の点数 |
| `type` | 種類（サーブ、注目スパイクなど） |
| `serve_side` | `A` / `B` |
| `serve_team` | チーム名 |
| `memo` | メモ |
| `record_id` | 記録ごとの固有番号（読み込むときの重複の判断に使う） |
| `no_count` | `1` なら、前のラリーはノーカウント（そのサーブで点を足さない） |

## データベースと同期

Firebase の Firestore（データベース）を使って、記録ファイルを渡し合わずに記録を共有できます。

接続先のデータベースは、ページやリポジトリには入れず、使う人それぞれがツールの中で設定します（ブラウザが覚えます）。ページは誰でも開けますが、設定していない人はどのデータベースにもつながりません。チームの 1 人が下の「Firebase の準備」をして、ほかの人には「設定リンク」を送ります。

### 最初の設定

**設定リンクを受け取った人**: リンクを開いて、「データベースの設定を取り込みますか？」で「設定する」を押すだけです。リンクを開けないときは、「設定」の「データベース」の欄にリンクを貼り付けて「決定」を押してください。

設定リンクを開くのは最初の 1 回だけにして、次からはふつうのページのリンク（`https://<ユーザー名>.github.io/<リポジトリ名>/`）で開いてください。設定はブラウザが覚えています。

- 設定リンクで開くと、設定を読み取ったところでアドレスバーから設定の部分（`#sync=…`）を消します。リロードしたり、「リンクをコピー」でリンクを作ったりしても、設定は入りません
- `#` から後ろはサーバーに送られないので、GitHub Pages にも設定は届きません
- 設定済みの人が設定リンクをもう一度開くと、「次からはふつうのページのリンクで開いてください」と出ます

**Firebase を用意した人**:

1. 「設定」を押して、「データベース」を開く
2. Firebase の接続情報（`firebaseConfig`。下の「Firebase の準備」の 4）を欄に貼り付ける。`const firebaseConfig = { … };` の部分をまるごと貼ってかまいません
3. 合言葉を入れるか「作る」で作って、「決定」を押す（英数字と `-` `_` で 8〜40 文字。同じ合言葉の人どうしで記録を共有します）。データベースにつながるかを確かめて、「データベースにつながりました」と出れば完了です
4. 「設定リンクをコピー」を押して、チームの人に LINE などで送る

設定リンクには接続先と合言葉が入っています。チームの外には送らないでください。設定は「設定」の「データベース」の「変更」で変えられます。設定がないまま「データベースと同期」を押すと、「設定を開く」ボタンが出ます。

### 使い方

1. 「データベースと同期」を押す
2. 同期する動画と、記録の種類を選んで「同期する」を押す

- 動画は「再生中の動画」「この再生リストのほかの動画」「ほかの動画」「データベースにだけある動画」に分かれて並びます。初めは再生中の動画だけにチェックが入っています。「すべて選ぶ」で全部選べます
- 種類（サーブ / 注目スパイク / 見返したい / セット切替 など）ごとに、送る件数と受け取る件数が出ます。チェックを外した種類は、データベースのものもこの端末のものもそのままで、やりとりしません
- 同期すると、選んだ動画ごとに「データベースの記録を読む → この端末の記録と合わせる → 合わせたものをデータベースに書き戻す」をします。2 人が同時に同期しても、あとから書いた人が先の人の分を消すことはありません（途中でほかの人が書き込んだら、自動でやり直します）

### 合わせ方

- 重複の扱いは「記録ファイル読み込み」と同じです（同じ記録、6 秒以内の同じチームのサーブ、5 分以内のセット切替、1 秒未満でメモが同じか片方が空の注目スパイク・見返したい）。ほかの人が記録した同じ場面は 1 つにまとめ、以後は同じ記録として扱います
- 同じ記録のメモやノーカウントの印を書き換えたときは、あとで書き換えた方を使います（同じ記録のメモを 2 人が別々に書き換えたときは、あとで書き換えた方だけが残ります）
- 記録を消すと、次に同期したときにデータベースからも消え、ほかの人も同期するとその人の端末からも消えます。消す前の確認画面にもそう出ます。消した記録を記録ファイルから読み込み直すと、新しい記録として戻ります

### チーム名

- チーム名が「Aチーム」「Bチーム」のまま（どちらか片方でも）の動画は、データベースにまだ無ければ送れません。同期の画面に「チーム名が初期のまま」と出るので、チーム名を入れてから同期してください（受け取る人がチーム名の対応を付けられるようにするため）
- データベースにすでにある動画は、データベースのチーム名と A・B に合わせます。自分のチーム名と違うときは、記録ファイル読み込みと同じ「チーム名の対応」が出ます。表示は自分のチーム名と左右の並びのままです
- 自分のチーム名が「Aチーム」「Bチーム」のままなら、データベースのチーム名がそのまま入ります（そのときも「チーム名の対応」で、自分の A・B がデータベースのどちらにあたるかを選べます）

### Firebase の準備

チームの 1 人だけがします。Google アカウントが 1 つあればでき、無料のプラン（Spark）で足ります。同じ手順は、ツールの「設定」の「データベースの用意のしかた」にも書いてあります。

1. [Firebase コンソール](https://console.firebase.google.com/)で「プロジェクトを作成」する（Google アナリティクスは使わなくてよい）
2. 左のメニューの「構築 → Firestore Database」で「データベースを作成」を押す。場所は `asia-northeast1`（東京）など近いところ、モードは「本番環境モード」でよい
3. 「ルール」のタブを開き、入っている文を消して、ルールを貼って「公開」する。ルールは、ツールの「設定」→「データベースの用意のしかた」の「ルールをコピー」でコピーできます（中身はこのリポジトリの `firestore.rules`）
4. 「プロジェクトの概要」の横の歯車 →「プロジェクトの設定」→「マイアプリ」で、ウェブ（`</>`）のアプリを追加する（ニックネームは何でもよい。Firebase Hosting は使わない）
5. 出てきた `firebaseConfig` を、上の「最初の設定」のとおりツールに貼り付ける（リポジトリには入れない）

### ほかのチームの人に使わせないために

- 接続先はリポジトリにもページにも入っていないので、ページを見つけただけの人は、このデータベースがあることもわかりません
- 設定リンクを手に入れた人でも、読み書きできるのはその合言葉の場所だけです。データの場所は `groups/{合言葉}/videos/{動画ID}` で、合言葉を知らない人は読めません（一覧も取れません）
- 設定リンクがチームの外に出てしまったときは、合言葉を変えて新しい設定リンクを送り直してください。前の合言葉のデータは見えなくなるので、先に全員が「すべて選ぶ」で同期しておき、合言葉を変えたあとにもう一度同期すると、新しい合言葉の場所に記録が送られます
- 接続情報（`apiKey` など）そのものは、Firebase の仕組み上パスワードではありません。守りはルールと合言葉です。もっと固くしたい（メンバーだけがログインして使う）ときは、Firebase Authentication で Google ログインにして、ルールで許可したメールアドレスだけにする方法があります
- チーム名が「Aチーム」「Bチーム」のままの動画は、ルールでも書き込めないようにしています
- ルールでドキュメントの削除はできないようにしています（記録を消したときは、中の `deleted` に消した記録の番号を残します）
- 合言葉は、ほかの人に推測されにくいもの（「作る」で作ったものなど）にしてください

### 別の Firebase に切り替える（試し用から本番へ）

コードの書き換えはいりません。別の Google アカウントの Firebase に切り替えるときは:

1. 切り替え先のアカウントで、上の「Firebase の準備」の 1〜4 をする（ルールも同じものを貼る）
2. 「設定」の「データベース」の「変更」で、切り替え先の接続情報を貼り付けて「決定」を押す
3. 「設定リンクをコピー」で新しい設定リンクを作り、チームの人に送り直す（開くと「今の設定から切り替わります」と出ます）

試し用のデータベースの記録を本番に移したいときは、切り替える前に「データベースと同期」で「すべて選ぶ」にして同期し、記録をいったん端末に取り込みます。切り替えたあとに、もう一度「すべて選ぶ」で同期すると、本番のデータベースに送られます（合言葉は同じでも、新しくしてもかまいません）。

### データ

ドキュメント（`groups/{合言葉}/videos/{動画ID}`）の中身は次のとおりです。

| 項目 | 内容 |
| --- | --- |
| `video_id` / `video_title` | 動画 ID・タイトル |
| `playlist_id` / `playlist_index` | 再生リスト ID・何本目か |
| `team_a` / `team_b` | チーム名（記録上の A・B） |
| `records` | 記録の一覧。1 件ごとに `record_id`、`seconds`、`type`、`serve_side`、`memo`、`no_count`、`updated_at`（書き換えた時刻） |
| `deleted` | 消した記録の `record_id` の一覧 |
| `updated_at` | 最後に書き込んだ時刻 |

## 共有リンク

「リンクをコピー」で、今の動画（または再生リスト）と、今表示しているチーム名を入れたリンクをコピーします。このリンクを開くと、同じ動画がすぐ読み込まれます。記録の中身はリンクに入りません。共有するときは CSV を渡すか、データベースと同期してください。

リンクには次の指定が使えます。

| 指定 | 意味 |
| --- | --- |
| `yt=<YouTubeのURL>` | 動画や再生リストの URL をそのまま渡す |
| `v=<動画ID>` | 動画 ID |
| `list=<再生リストID>` | 再生リスト ID |
| `t=90` | 開始位置（秒。`1m30s` の形も可） |
| `index=3` | 再生リストの何本目から始めるか |
| `ta=<名前>` / `tb=<名前>` | チーム名 |

例: `index.html?v=XXXXXXXXXXX&ta=東高&tb=西高&t=120`

## 公開のしかた

YouTube の埋め込み再生は、ファイルを直接開く（`file://`）と動かないことがあります（エラー 153）。Web アドレスで開いてください。

GitHub Pages を使う場合:

1. リポジトリの **Settings → Pages** を開く
2. **Source** を「Deploy from a branch」、ブランチを `main`、フォルダを `/ (root)` にして保存する
3. しばらくすると `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けるようになる

## 注意

- 記録・チーム名は、ブラウザに自動で保存されます。再読み込みしたり閉じて開き直したりしても消えません
- 動画の指定なしでページを開くと、空の状態で始まります（保存された記録は、その動画を開くと表に出ます）。同じタブで読み込み直したときは、開いていた動画をもう一度開きます
- 動画ごとに見ていた位置を覚えていて、ページを開いたときにその動画ならそこから再生できます
- 複数のタブで開いて記録しても、ほかのタブの記録は消えません（どのタブにも全部の記録が反映されます）
- 保存先はそのブラウザの中だけです。別の端末や別のブラウザには引き継がれません（データベースと同期すれば、同じ合言葉で別の端末にも取り込めます）。ブラウザのデータを消すと記録も消えるので、大事な記録は CSV で書き出すか、データベースと同期しておいてください
- iPhone / iPad の Safari は、7 日間そのページを開かないと保存した記録を消すことがあります。ホーム画面に追加して使うと消えにくくなります
- プライベートブラウズなどで保存できないときは、記録があると閉じる前に確認が出ます
- 埋め込み再生が禁止されている動画や、非公開の動画は再生できません
